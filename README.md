# Job Tracker

A full-stack Job Tracker application to manage and track job applications.

## Features

- User Registration
- User Login
- JWT Authentication
- Add Job Application
- View Job Applications
- Edit Job Application
- Delete Job Application
- Search Applications
- Filter Applications by Status
- Dashboard with Application Statistics
- Protected Routes
- Logout

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- JWT
- bcrypt
- MySQL
